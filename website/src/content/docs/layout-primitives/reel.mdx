# Reel

Displays child elements in a simple horizontal scroll.

## Usage

<PreviewConainer>
	<Reel>
		<DummyImage />
		<DummyImage />
		<DummyImage />
	</Reel>
</PreviewConainer>

<Tabs items={['HTML', 'JSX']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="reel">
			<img src="..." alt="" />
			<img src="..." alt="" />
			<img src="..." alt="" />
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Reel } from '@inc2734/unitone-css/layout-primitives/reel/react';

		<Reel>
			<img src="..." alt="" />
			<img src="..." alt="" />
			<img src="..." alt="" />
		</Reel>
		```
	</Tabs.Tab>
</Tabs>

### <Badge>HTML</Badge> -gap:\{variation\} / <Badge>JSX</Badge> gap=\{variation\}

Gap.

Can be set from `-3` to `7`. For variations `2` and above, `clamp` is used to adjust the margins so that they do not become too large on small screens.
If it is `1` or more, adding `s` will shrink it to size `-1` on mobile. (e.g. `1s`)
If it is `2` or more, adding `m` will shrink it to size `1` on mobile. (e.g. `2m`)

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="reel -gap:-2">
			...
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Reel } from '@inc2734/unitone-css/layout-primitives/reel/react';

		<Reel gap={-2}>
			...
		</Reel>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		<PreviewConainer>
			<Reel gap={-2}>
				<DummyImage />
				<DummyImage />
				<DummyImage />
			</Reel>
		</PreviewConainer>
	</Tabs.Tab>
</Tabs>

### <Badge>HTML</Badge> -container-type:\{value\} / <Badge>JSX</Badge> containerType=\{value\}

Establishes the Reel as a query container for its descendants.

Currently supported values are:

- `inline-size`

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="reel -container-type:inline-size">
			<div>...</div>
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Reel } from '@inc2734/unitone-css/layout-primitives/reel/react';

		<Reel containerType="inline-size">
			<div>...</div>
		</Reel>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		<PreviewConainer>
			<Reel containerType="inline-size">
				<div style={{ outline: '1px dotted #6366f1', padding: '1em' }}>
					Lorem ipsum dolor sit amet, consectetur adipisicing elit
				</div>
			</Reel>
		</PreviewConainer>
	</Tabs.Tab>

### <Badge>HTML</Badge> -fluid-reference:\{value\} / <Badge>JSX</Badge> fluidReference=\{value\}

Uses a query container's inline size as the reference for fluid typography, spacing, padding, and gutters.

Currently supported values are:

- `cqw`

Place the Reel inside an ancestor with `container-type: inline-size`.
