# Frame

Constrains media to a chosen aspect ratio.
Overflow is cropped so images and videos fit cleanly within the frame.

## Usage

<PreviewConainer>
	<Frame>
		<DummyImage />
	</Frame>
</PreviewConainer>

<Tabs items={['HTML', 'JSX']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="frame">
			<img src="..." alt="" style="width: 100%" />
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Frame } from '@inc2734/unitone-css/layout-primitives/frame/react';

		<Frame>
			<img src="..." alt="" />
		</Frame>
		```
	</Tabs.Tab>
</Tabs>

## Props

### <Badge>HTML</Badge> --unitone--ratio / <Badge>JSX</Badge> ratio=\{value\}

Aspect ratio.

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="frame" style="--unitone--ratio: 4/3">
			<img src="..." alt="" style="width: 100%" />
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Frame } from '@inc2734/unitone-css/layout-primitives/frame/react';

		<Frame ratio="4/3">
			<img src="..." alt="" />
		</Frame>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		<PreviewConainer>
			<Frame ratio="4/3">
				<DummyImage />
			</Frame>
		</PreviewConainer>
	</Tabs.Tab>
</Tabs>

### <Badge>HTML</Badge> -switch / <Badge>JSX</Badge> switchRatio

Switch aspect ratio when portrait and mobile width.

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="frame -switch">
			<img src="..." alt="" style="width: 100%" />
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Frame } from '@inc2734/unitone-css/layout-primitives/frame/react';

		<Frame switchRatio>
			<img src="..." alt="" />
		</Frame>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		<PreviewConainer>
			<Frame switchRatio>
				<DummyImage />
			</Frame>
		</PreviewConainer>
	</Tabs.Tab>
</Tabs>

Set the query context to `container` to make the responsive behavior depend on the containing element's width instead of the viewport width.
For HTML, add `@container` to `data-unitone-layout`. For React, set `queryContext="container"`.

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div style="max-width: 375px; container-type: inline-size">
			<div data-unitone-layout="frame -switch @container">
				<img src="..." alt="" style="width: 100%" />
			</div>
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Frame } from '@inc2734/unitone-css/layout-primitives/frame/react';

		<div style={{ maxWidth: '375px', containerType: 'inline-size' }}>
			<Frame switchRatio queryContext="container">
				<img src="..." alt="" />
			</Frame>
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		<PreviewConainer>
			<div style={{ maxWidth: '375px', containerType: 'inline-size' }}>
				<Frame switchRatio queryContext="container">
					<DummyImage />
				</Frame>
			</div>
		</PreviewConainer>
	</Tabs.Tab>
</Tabs>
