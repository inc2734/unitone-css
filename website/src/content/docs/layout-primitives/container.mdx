# Container

## Props

### <Badge>HTML</Badge> -gutters:\{variation\} / <Badge>JSX</Badge> gutters=\{variation\}

Gutters.

Can be set from `-3` to `7`. For variations `2` and above, `clamp` is used to adjust the margins so that they do not become too large on small screens.
If it is `1` or more, adding `s` will shrink it to size `-1` on mobile. (e.g. `1s`)
If it is `2` or more, adding `m` will shrink it to size `1` on mobile. (e.g. `2m`)

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="container -gutters:-2">
			...
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Container } from '@inc2734/unitone-css/layout-primitives/container/react';

		<Container gutters={-2}>
			Lorem ipsum dolor sit amet, consectetur adipisicing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in reprehenderit in voluptate velit esse cill
		</Container>
		```

### <Badge>HTML</Badge> -container-type:\{value\} / <Badge>JSX</Badge> containerType=\{value\}

Establishes the Container as a query container for its descendants.

Currently supported values are:

- `inline-size`

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="container -container-type:inline-size">
			<div>...</div>
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Container } from '@inc2734/unitone-css/layout-primitives/container/react';

		<Container containerType="inline-size">
			<div>...</div>
		</Container>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		<PreviewConainer>
			<Container containerType="inline-size">
				<div style={{ outline: '1px dotted #6366f1', padding: '1em' }}>
					Lorem ipsum dolor sit amet, consectetur adipisicing elit
				</div>
			</Container>
		</PreviewConainer>
	</Tabs.Tab>
</Tabs>

### <Badge>HTML</Badge> -fluid-reference:\{value\} / <Badge>JSX</Badge> fluidReference=\{value\}

Uses a query container's inline size as the reference for fluid typography, spacing, padding, and gutters.

Currently supported values are:

- `cqw`

Place the Container inside an ancestor with `container-type: inline-size`.
