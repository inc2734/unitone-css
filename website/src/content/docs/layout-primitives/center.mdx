# Center

Center the box. Settings also allow for centering of child elements and centering of text.

## Usage

<PreviewConainer>
	<Stack>
		<Center style={{ outline: '1px dotted #6366f1' }}>Lorem ipsum dolor sit amet, consectetur adipisicing elit</Center>
		<Center style={{ outline: '1px dotted #6366f1' }}>Lorem ipsum dolor sit amet, consectetur adipisicing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam</Center>
	</Stack>
</PreviewConainer>

<Tabs items={['HTML', 'JSX']}>
	<Tabs.Tab>

### <Badge>HTML</Badge> -gutters:\{variation\} / <Badge>JSX</Badge> gutters=\{variation\}

Gutters.

Can be set from `-3` to `7`. For variations `2` and above, `clamp` is used to adjust the margins so that they do not become too large on small screens.
If it is `1` or more, adding `s` will shrink it to size `-1` on mobile. (e.g. `1s`)
If it is `2` or more, adding `m` will shrink it to size `1` on mobile. (e.g. `2m`)

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="center -gutters:1">
			...
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Center } from '@inc2734/unitone-css/layout-primitives/center/react';
		import { Stack } from '@inc2734/unitone-css/layout-primitives/stack/react';

		<Center gutters={1}>
			...
		</Center>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		<PreviewConainer>
			<Stack>
				<Center gutters={1} style={{ outline: '1px dotted #6366f1' }}>Lorem ipsum dolor sit amet, consectetur adipisicing elit</Center>
				<Center gutters={1} style={{ outline: '1px dotted #6366f1' }}>Lorem ipsum dolor sit amet, consectetur adipisicing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam</Center>

### <Badge>HTML</Badge> -container-type:\{value\} / <Badge>JSX</Badge> containerType=\{value\}

Establishes the Center as a query container for its descendants.

Currently supported values are:

- `inline-size`

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="center -container-type:inline-size">
			<div>...</div>
		</div>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		```jsx
		import { Center } from '@inc2734/unitone-css/layout-primitives/center/react';

		<Center containerType="inline-size">
			<div>...</div>
		</Center>
		```
	</Tabs.Tab>
	<Tabs.Tab>
		<PreviewConainer>
			<Center containerType="inline-size">
				<div style={{ outline: '1px dotted #6366f1', padding: '1em' }}>
					Lorem ipsum dolor sit amet, consectetur adipisicing elit
				</div>
			</Center>
		</PreviewConainer>
	</Tabs.Tab>
</Tabs>

### <Badge>HTML</Badge> -fluid-reference:\{value\} / <Badge>JSX</Badge> fluidReference=\{value\}

Uses a query container's inline size as the reference for fluid typography, spacing, padding, and gutters.

Currently supported values are:

- `cqw`

Place the Center inside an ancestor with `container-type: inline-size`.

<Tabs items={['HTML', 'JSX', 'Preview']}>
	<Tabs.Tab>
		```html
		<div data-unitone-layout="center -container-type:inline-size">

		</div>
		```
