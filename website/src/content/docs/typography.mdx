# Typography

## Font size

Use font-size tokens or the `-font-size:*` utility to scale text. Variations are generated from the harmonic sequence, and they update when `--unitone--harmonic-sequence-base` or `--unitone--root-font-size` changes.

The automatic `line-height` optimization still follows the rendered font size. By default, it scales from `1.1`(= `1 + var(--unitone--min-half-leading) * 2`) to `1.6`(= `1 + var(--unitone--half-leading) * 2`).

Approximate font sizes with the default `--unitone--root-font-size: 16px` are:

| Token                         | Utility class     | Approx. rem | Approx. px |
| ----------------------------- | ----------------- | ----------- | ---------- |
| `--unitone--font-size-2xs`    | `.-font-size:2xs` | `0.727rem`  | `11.6px`   |
| `--unitone--font-size-xs`     | `.-font-size:xs`  | `0.8rem`    | `12.8px`   |
| `--unitone--font-size-s`      | `.-font-size:s`   | `0.889rem`  | `14.2px`   |
| `--unitone--font-size-m`      | `.-font-size:m`   | `1rem`      | `16px`     |
| `--unitone--font-size-l`      | `.-font-size:l`   | `1.143rem`  | `18.3px`   |
| `--unitone--font-size-xl`     | `.-font-size:xl`  | `1.333rem`  | `21.3px`   |
| `--unitone--font-size-2xl`    | `.-font-size:2xl` | `1.6rem`    | `25.6px`   |
| `--unitone--font-size-3xl`    | `.-font-size:3xl` | `2rem`      | `32px`     |
| `--unitone--font-size-4xl`    | `.-font-size:4xl` | `2.667rem`  | `42.7px`   |
| `--unitone--font-size-5xl`    | `.-font-size:5xl` | `4rem`      | `64px`     |
| `--unitone--font-size-6xl`    | `.-font-size:6xl` | `8rem`      | `128px`    |

These are static size approximations. When `-fluid-typography` is used, the actual rendered size changes within a range based on the active responsive context, which is the viewport by default.

When using large font sizes such as `2xl` and above, combining them with `-fluid-typography` is recommended. This helps prevent oversized text from breaking the layout on mobile screens.

For plain HTML, use the utility class from `utilities.mdx`, such as `class="-font-size:xl"`.

When utilities are not loaded but the font-size behavior is loaded, use the `data-unitone-layout` version.
The leading `.` seen in CSS selector notation is not included in the class attribute value.

```html
<p class="-font-size:xl">
	...
</p>
```

```html
<p data-unitone-layout="-font-size:xl">
	...
</p>
```

In custom CSS, set the `font-size` property directly.

```css
.foo {
	font-size: var(--unitone--font-size-xl);
}
```

## Line height

The half leading can be set. The default value is `0.3`.

```html
<p style="--unitone--half-leading: 0.3">
	...
</p>
```

## Fluid typography

Combine a font-size utility with `-fluid-typography` to switch from the static token to the matching fluid token.

Approximate fluid font-size ranges with the default `--unitone--root-font-size: 16px` are:

| Fluid token                   | Utility class     | Min rem    | Min px   | Max rem    | Max px   |
| ----------------------------- | ----------------- | ---------- | -------- | ---------- | -------- |
| `--unitone--font-size-2xs-fluid` | `.-font-size:2xs` | `0.727rem` | `11.6px` | `0.727rem` | `11.6px` |
| `--unitone--font-size-xs-fluid`  | `.-font-size:xs`  | `0.8rem`   | `12.8px` | `0.8rem`   | `12.8px` |
| `--unitone--font-size-s-fluid`   | `.-font-size:s`   | `0.889rem` | `14.2px` | `0.889rem` | `14.2px` |
| `--unitone--font-size-m-fluid`   | `.-font-size:m`   | `1rem`     | `16px`   | `1rem`     | `16px`   |
| `--unitone--font-size-l-fluid`   | `.-font-size:l`   | `1.089rem` | `17.4px` | `1.143rem` | `18.3px` |
| `--unitone--font-size-xl-fluid`  | `.-font-size:xl`  | `1.2rem`   | `19.2px` | `1.333rem` | `21.3px` |
| `--unitone--font-size-2xl-fluid` | `.-font-size:2xl` | `1.343rem` | `21.5px` | `1.6rem`   | `25.6px` |
| `--unitone--font-size-3xl-fluid` | `.-font-size:3xl` | `1.533rem` | `24.5px` | `2rem`     | `32px`   |
| `--unitone--font-size-4xl-fluid` | `.-font-size:4xl` | `1.8rem`   | `28.8px` | `2.667rem` | `42.7px` |
| `--unitone--font-size-5xl-fluid` | `.-font-size:5xl` | `2.2rem`   | `35.2px` | `4rem`     | `64px`   |
| `--unitone--font-size-6xl-fluid` | `.-font-size:6xl` | `2.867rem` | `45.9px` | `8rem`     | `128px`  |

These values are the approximate minimum and maximum lengths generated by `clamp()` across the default viewport range.

When using large font sizes such as `2xl` and above, combining them with `-fluid-typography` is recommended. This helps prevent oversized text from breaking the layout on mobile screens.

In plain HTML, the utility version is a class:

```html
<p class="-font-size:6xl -fluid-typography">
	...
</p>
```

The same combination can be written with `data-unitone-layout`.

```html
<p data-unitone-layout="-font-size:6xl -fluid-typography">
	...
</p>
```

In custom CSS, use the fluid token directly.

```css
.foo {
	font-size: var(--unitone--font-size-6xl-fluid);
}
```

### Custom minimum and maximum sizes

Set `--unitone--fluid-typography-min-length` and/or `--unitone--fluid-typography-max-length` on the element that uses fluid typography. These bounds work with attributes, utility classes, and direct fluid-token references.

```html
<div
	data-unitone-layout="-font-size:3xl -fluid-typography"
	style="--unitone--fluid-typography-min-length:28px"
>
	Text
</div>
```

```css
.example {
	--unitone--fluid-typography-min-length: 28px;
	--unitone--fluid-typography-max-length: 30px;
	font-size: var(--unitone--font-size-3xl-fluid);
}
```

With a 16px root font size and a 400px viewport, these examples render at 28px. The bounds only change the limits of `clamp()`; they do not change the interpolation slope. Omitted bounds use the original scale limits. Bounds inherit from ancestors, can be overridden on descendants, and update when their declarations change or are removed.

The active reference stays the same: the viewport by default, or the width captured at a `responsiveContext` or legacy `fluidReference` boundary. Deep descendants keep that reference until another boundary changes it. Bounds are evaluated on each element, including when it directly references a public `--unitone--font-size-*-fluid` token.

Fluid tokens are now declared on every element to support local bounds. If custom CSS replaces a public fluid token itself, apply that replacement to the consuming elements; a replacement declared only on an ancestor no longer overrides their local tokens. Static font-size tokens retain their existing inheritance.

Use `-responsive-context:container` together with `-container-type:inline-size` on the same ancestor to switch its descendants to container-width-based fluid typography.

Both markers must be on the same element for the context to become active. An unpaired context marker is ignored: fluid typography keeps using the existing context, which is the viewport by default. Only the container context is supported. See [Responsive context utilities](/utilities#responsive-context) for examples and the behavior when markers are missing or separated.

```html
<div data-unitone-layout="decorator -container-type:inline-size -responsive-context:container">
	<p data-unitone-layout="-font-size:6xl -fluid-typography">
		...
	</p>
</div>
```

or

```html
<div class="-container-type:inline-size -responsive-context:container">
	<p class="-font-size:6xl -fluid-typography">
		...
	</p>
</div>
```

## Text wrapping

Use `-text-wrap:*` to control text wrapping with the CSS `text-wrap` property. It is available as both a behavior in `data-unitone-layout` and a utility class.

| Value | Effect |
| --- | --- |
| `wrap` | Wrap text normally when it reaches the available width. |
| `nowrap` | Disable automatic wrapping. Explicit line breaks such as `br` still apply. |
| `balance` | Adjust line breaks to make line lengths more even, for example in headings. |
| `pretty` | Favor better line breaks over speed, for example to avoid a very short last line in a paragraph. |

The exact line breaks produced by `balance` and `pretty` depend on the browser. See the [CSS text wrapping specification](https://drafts.csswg.org/css-text-4/#text-wrap) for details.

Use the behavior when specifying wrapping through `data-unitone-layout`:

```html
<h2 data-unitone-layout="-text-wrap:balance">
	A heading with more evenly balanced lines
</h2>
```

Use the utility class on plain text elements:

```html
<p class="-text-wrap:pretty">
	A paragraph whose line breaks are adjusted for readability.
</p>
```

Both forms support all four values. The behavior sets `text-wrap` with `!important`; the utility sets it without `!important`.

Headings inside the `text` primitive already use `text-wrap: pretty`. Apply `-text-wrap:*` directly to a heading to override that default.

## Auto line breaks

Use `-auto-phrase` for automatic line breaks. It combines `overflow-wrap: anywhere` with `word-break: auto-phrase` to keep natural phrases together where supported. Browsers that do not support the `auto-phrase` value fall back to `word-break: keep-all`.

The behavior declares `keep-all` before `auto-phrase`, so browsers that do not recognize the latter ignore it. If a browser recognizes `auto-phrase` but cannot detect phrase boundaries for the content language, it behaves like `normal`, as defined in the [CSS specification](https://www.w3.org/TR/css-text-4/#valdef-word-break-auto-phrase).

Use `wbr` to indicate a line break opportunity at an arbitrary position.

```html
<p data-unitone-layout="-auto-phrase">
	...
</p>
```
